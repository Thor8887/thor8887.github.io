# AGENTS.md

Ce site est le site professionnel d'Akanomad, musicien, compositeur et producteur.

## Objectifs

- Conserver une esthetique sobre, elegante, organique et professionnelle.
- Eviter les formulations marketing trop agressives.
- Privilegier la clarte, la legerete et la lisibilite mobile.
- Ne jamais modifier les textes biographiques sans proposition claire et validation explicite.
- Ne jamais supprimer une page, une image ou un lien externe sans confirmation.
- Optimiser les images avant ajout lorsque c'est pertinent.
- Verifier le rendu mobile et desktop apres toute modification visuelle.

## Structure du depot

- `index.html` : page d'accueil.
- `style.css` : styles globaux du site.
- `posts/` : articles ou publications, si le dossier est present.
- Les pages HTML a la racine servent de pages principales du site.

## Commandes

Ce depot est actuellement un site statique HTML/CSS simple, sans configuration `npm` detectee.

- Aucun build n'est requis pour publier les changements.
- Pour verifier localement, ouvrir `index.html` dans un navigateur ou servir le dossier avec un serveur statique simple.
- Si une configuration de build est ajoutee plus tard, mettre a jour cette section avec les commandes exactes.

## Definition de termine

- Les changements sont limites a la tache demandee.
- Aucun lien interne important n'est casse.
- Le rendu mobile et desktop est verifie pour toute modification visuelle.
- Les pages modifiees restent lisibles, rapides et sobres.
- Les fichiers ajoutes ou modifies ont des noms clairs et restent faciles a maintenir.
